# Tasks CRUD API

A minimal RESTful CRUD API for managing tasks, built with **FastAPI** and
**SQLite3**. Created as a demonstration of standard CRUD operations behind
a clean, three-layer structure.

## Features

- Full CRUD for a single `tasks` resource (Create, Read, Update, Delete)
- Auto-creates the SQLite table and seeds 3 dummy tasks on first run
- Interactive API docs via Swagger UI (and ReDoc)
- Fully typed request/response schemas (Pydantic)
- No auth, no ORM, no service layer — intentionally minimal

## Tech Stack

| Layer         | Technology       |
| ------------- | ---------------- |
| Language      | Python 3.10+     |
| Web framework | FastAPI          |
| Server        | Uvicorn          |
| Database      | SQLite3 (stdlib) |
| Docs          | Swagger UI / ReDoc (auto-generated by FastAPI) |

## Project Structure

```
crud-api/
├── main.py                       # FastAPI app, Pydantic schemas, routes
├── database.py                   # Connection lifecycle + schema/seed init
├── repositories/
│   ├── __init__.py
│   └── task_repository.py        # All SQL for the `tasks` table
├── requirements.txt
└── app.db                        # created automatically on first run
```

**Layering:**
`main.py` (routes/schemas) → `repositories/task_repository.py` (SQL) →
`database.py` (connection management). Nothing above the repository layer
touches raw SQL.

## Requirements

- Python 3.10 or newer
- pip

## Setup & Run

```bash
# 1. (Recommended) create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the server
uvicorn main:app --reload
```

The API is now running at **http://127.0.0.1:8000**.

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

On first startup, `app.db` is created automatically in the project folder,
with the `tasks` table and 3 seed rows. To reset all data, stop the server
and delete `app.db`, then restart.

## Data Model

`tasks` table:

| Column | Type    | Notes                          |
| ------ | ------- | ------------------------------- |
| id     | INTEGER | Primary key, autoincrement     |
| title  | TEXT    | Required                       |
| done   | BOOLEAN | Defaults to `false`            |

## API Endpoints

| Method | Endpoint      | Description                  |
| ------ | ------------- | ----------------------------- |
| GET    | `/`           | Home                          |
| GET    | `/health`     | Check API status              |
| GET    | `/tasks`      | Retrieve all tasks            |
| GET    | `/tasks/{id}` | Retrieve a task by ID         |
| GET    | `/tasks/`     | Retrieve all tasks by done    |
| GET    | `/stats`      | Retrieve tasks stats by done  |
| POST   | `/tasks`      | Create a new task             |
| PUT    | `/tasks/{id}` | Update an existing task       |
| DELETE | `/tasks/{id}` | Delete a task                 |

### Example requests

**List all tasks**
```bash
curl http://127.0.0.1:8000/tasks
```

**Get a task by ID**
```bash
curl http://127.0.0.1:8000/tasks/1
```

**Filter tasks by done status**
```bash
curl "http://127.0.0.1:8000/tasks/?done=true"
```

**Get stats**
```bash
curl http://127.0.0.1:8000/stats
# {"total": 3, "done": 1, "not_done": 2}
```

**Create a task**
```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Write tests", "done": false}'
```

**Update a task**
```bash
curl -X PUT http://127.0.0.1:8000/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"title": "Buy groceries", "done": true}'
```

**Delete a task**
```bash
curl -X DELETE http://127.0.0.1:8000/tasks/1
```

## Notes / Out of Scope

- No authentication or authorization — every endpoint is public.
- No ORM — raw `sqlite3` is used directly, confined to the repository layer.
- No pagination — `GET /tasks` returns the full table (fine for demo scale).
